# 📊 Sample Superstore Sales Analysis Dashboard

## 📌 Project Overview
This project focuses on analyzing the Sample Superstore dataset using Microsoft Power BI. The objective is to transform raw sales data into meaningful insights through interactive data visualization and business intelligence reporting.

The dashboard helps understand sales performance, business trends, and key performance indicators (KPIs) to support data-driven decision-making.

## 🎯 Project Objectives
- Analyze overall sales performance.
- Understand business and sales trends.
- Identify key performance indicators.
- Explore data through interactive visualizations.
- Present meaningful insights for better business decisions.

## 🛠️ Tools & Technologies
- **Microsoft Power BI Desktop** – Dashboard development and visualization.
- **Power Query** – Data cleaning and transformation.
- **DAX (Data Analysis Expressions)** – Calculations and measures.
- **Sample Superstore Dataset** – Data source.

## 📈 Dashboard Features
- Interactive data visualization.
- Sales performance analysis.
- KPI-based reporting.
- Data filtering and exploration.
- Business performance insights.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open the `arman.pbix` file.
4. If required, update the dataset file path.
5. Refresh the data.
6. Explore the interactive dashboard.
